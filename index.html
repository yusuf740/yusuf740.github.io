Selected work

Things I've built & helped build

ModernBERT-TR

Academic research · Turkish encoder models · YTU COSMOS

An academic study introducing a 149.4M-parameter Turkish encoder with an 8,192-token context, along with open downstream models and new Turkish datasets (Guardrail-TR, ABSA-TR). It also reports benchmarks against existing Turkish encoders and findings on checkpoint merging. I worked on fine-tuning the downstream models.

Read the paper page ↗

DEFFBOSS

Real-time threat detection · SKY LAB / AIRLAB · YOLOv8n

A six-class detector for knives, firearms and physical fights. I worked on data collection, processing and training; phones, remotes and non-violent contact got their own classes to cut false alarms. 88.37% mAP@50 on validation.

Kaggle model card ↗

SesOl

Turkish Sign Language recognition · Project lead · PyTorch

Recognises 226 signs from the AUTSL dataset using 48 MediaPipe landmarks from the hands and upper body: a GCN for spatial structure, a Bi-LSTM for motion. I led planning, task split, integration and code review.

Tabio

AI assistant for cafés & restaurants · FastAPI · TypeScript · PostgreSQL

An agent for a multi-tenant POS: natural-language request → validated plan → user approval → safe execution → audit log & undo. The model can only pick from a closed command catalogue, and sales figures are computed by deterministic code.
